# Site Neway

Site institucional da Neway, com foco em antecipação de recebíveis de contratos públicos.

## Uso
Abra index.html no navegador ou sirva esta pasta como site estático. Sem etapa de compilação.

## Processo
1. Recebimento dos documentos
2. Análise
3. Trava perfeita
4. Antecipação

## Contato
O formulário prepara uma mensagem para copiar. O canal oficial de atendimento ainda precisa ser configurado; nenhum dado é enviado.

## Identidade
Logo e imagens extraídos do moodboard fornecido. Paleta e tipografia baseadas no brand book Neway.
